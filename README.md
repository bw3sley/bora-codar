# #boraCodar
#boraCodar é um desafio semanal de programação oferecido pela [@Rocketseat](https://www.rocketseat.com.br/), com objetivo de ajudar participantes a evoluir habilidades em HTML, CSS e JavaScript. A cada semana, um novo desafio é apresentado por [Mayk Brito](https://github.com/maykbrito). Os desafios variam de tarefas simples a projetos mais complexos, pensados para serem acessíveis a programadores de todos os níveis. [Acesse o desafio da semana](https://www.rocketseat.com.br/boracodar).
